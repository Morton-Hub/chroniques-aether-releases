# Chroniques d'Aether — APK Android

RPG tactique fantasy solo, hors ligne, pour Android (paysage, tactile).

### [⬇ Télécharger la dernière version](https://github.com/Morton-Hub/chroniques-aether-releases/releases/latest/download/chroniques-aether.apk)

1. Ouvre le lien depuis le navigateur du téléphone et télécharge `chroniques-aether.apk`.
2. Ouvre le fichier et autorise l'installation depuis cette source.
3. Ensuite, le jeu se met à jour lui-même : *Paramètres → Mises à jour → Vérifier les mises à jour*.
   La première fois, Android demande d'autoriser Chroniques d'Aether à installer des applications.

Chaque version s'installe par-dessus la précédente et conserve la partie (une désinstallation
l'efface). Ce dépôt ne contient que les versions publiées : chaque Release porte l'APK et un
`version.json` lu par le jeu.
